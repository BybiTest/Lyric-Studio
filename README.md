# استودیو ترانه • Lyric Studio 🎙️

اپلیکیشن حرفه‌ای، تخصصی و ۱۰۰٪ آفلاین ترانه‌سرایی، سرودن شعر، رپ و بیت‌نویسی با طراحی استودیویی، تم تاریک مشکی متالیک و پشتیبانی دو زبانه (فارسی و انگلیسی با چیدمان کامل RTL).

---

## راهنمای بیلد و اجرا (Build & Run Guide)

### پیش‌نیازها
- **JDK 17** یا بالاتر
- **Android SDK** با Compile SDK 36 (یا Target SDK 35/36)

### بیلد از طریق Gradle Wrapper (توصیه‌شده)

در لینوکس و مک:
```bash
chmod +x gradlew
./gradlew assembleDebug
```

در ویندوز:
```cmd
gradlew.bat assembleDebug
```

اگر به هر دلیلی فایل باینری `gradle/wrapper/gradle-wrapper.jar` در گیت موجود نبود یا نیاز به بازسازی مجدد داشتید، می‌توانید با دستور زیر مجدداً آن را بسازید:
```bash
gradle wrapper
```

## ویژگی‌های اصلی

1. **ویرایشگر تخصصی ترانه (Core Lyric Editor):**
   - تفکیک قطعه‌ها به بندها و بخش‌های استاندارد (Verse, Chorus, Hook, Pre-Chorus, Bridge, Outro و ...)
   - ذخیره خودکار بدون وقفه با تاخیر ۶۰۰ میلی‌ثانیه‌ای (Debounced Autosave)
   - آمار لحظه‌ای واژگان، حروف، سطرها و زمان خوانش
   - حالت تمام‌صفحه بدون حواس‌پرتی (Focus Mode)

2. **ابزارهای ترانه‌سرایی (Songwriting Suite):**
   - **مترونوم و تپ‌تمپو:** رنج ۴۰ تا ۲۴۰ BPM با فلاش تصویری و فیدبک لرزشی
   - **ضبط و مدیریت یادداشت‌های صوتی:** ضبط زمزمه ملودی‌ها و ایده‌های آوازی
   - **قافیه‌یاب آفلاین:** دسترسی سریع به کلمات هم‌قافیه فارسی و انگلیسی
   - **گنجینه پانچ‌لاین‌ها:** ذخیره بیت‌ها و خطوط کوبنده با قابلیت کپی فوری
   - **بانک واژگان و اصطلاحات:** آرشیو لغات خاص و استعاره‌ها

3. **امنیت و حریم خصوصی:**
   - قفل برنامه با کد امنیتی PIN
   - سطل زباله (Trash Bin) با امکان بازیابی یا حذف دائمی
   - ذخیره‌سازی محلی و امن در پایگاه داده Room بدون ارسال هیچ داده‌ای به سرور خارجی
